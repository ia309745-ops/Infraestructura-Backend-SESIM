# Arquitectura SESIM — Ciclo 1

Diagrama interactivo (HTML autocontenido) de la arquitectura de SESIM sobre Supabase autoalojado.

## Ver en línea

Si este repo tiene GitHub Pages activado (Settings → Pages → Deploy from branch → `main` / `(root)`), el diagrama queda disponible en:

```
https://<tu-usuario>.github.io/<nombre-del-repo>/
```

## Ver localmente

Descarga `index.html` y ábrelo en cualquier navegador — no necesita instalación ni servidor.
